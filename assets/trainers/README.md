# Trainer versus cut-in assets

The game stores these cut-in sprites locally and randomly chooses one for each NPC challenge. The displayed trainer name is derived from the local filename stem; the `VS` prefix from source filenames is omitted.

- Generation IV: 49 sprites from [Bulbagarden Archives — Generation IV Versus Trainer sprites](https://archives.bulbagarden.net/wiki/Category:Generation_IV_Versus_Trainer_sprites).
- Generation VII: 7 selected sprites from [Bulbagarden Archives — Generation VII Versus Trainer sprites](https://archives.bulbagarden.net/wiki/Category:Generation_VII_Versus_Trainer_sprites).

The local PNG names use the source filename with a leading `VS` removed. Each image is stored alongside its source file name and is loaded once at game startup. The linked archive pages contain file credits and usage notes.
